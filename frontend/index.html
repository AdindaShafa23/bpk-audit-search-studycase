    Cara kerja

    1. File disimpan ke object storage & antrean, API langsung membalas 202 Accepted.
    2. Worker fast mengambil teks asli PDF.
    3. Halaman scan dikirim ke worker OCR (Tesseract) di antrean terpisah.
    4. Teks diindeks ke Elasticsearch → pencarian & dashboard ikut berubah otomatis.

    Perhatikan waktu respons unggah di bawah form: tetap singkat walau OCR berat.
